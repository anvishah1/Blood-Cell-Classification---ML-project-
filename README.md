# Blood-Cell-Classification---ML-project-
a CNN model - fine-tuning efficientNet_b4 for classifying blood cells into - monocytes, lymphocytes, eosinophil and neutrophils

acheived an accuracy of 89.3% by fine-tuning efficientnet_b4 using augmentations and changing the class weights
loss fucntion used : LabelSmoothingCrossEntropy
